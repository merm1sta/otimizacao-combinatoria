# otimizacao-combinatoria
Esse repositório contém estratégias de otimização conhecidas e amplamente utilizadas em problemas clássicos. Ao todo, são três algoritmos: Simulated Annealing, Dynamic Programming e Greedy Algorithm, utilizados, respectivamente, para solucionar o Problema do Caixeiro Viajante, Problema do Empacotamento Unidimensional e Problema das N-Rainhas.
